Select Game Mode

Select a game mode to begin. In "Computer Guesses" mode, think of a number between 1-100 and the computer will try to guess it. In "You Guess" mode, you'll try to guess the computer's secret number.

How to Play

  • Computer Guesses: Think of a number between 1-100. The computer will try to guess it. Tell the computer if its guess is too high, too low, or correct.
  • You Guess: The computer picks a random number between 1-100. You try to guess it, and the computer will tell you if your guess is too high or too low.
  • Try to win in as few guesses as possible!
